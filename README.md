# Social Network Homepage Recreation

This project is a **HTML and CSS-only** recreation of a social network homepage, designed as a personal exercise to improve front-end development skills.

## 🖼 Project Overview  
The design replicates the layout and key components of a modern social media homepage, including:  
- Navigation bar with profile and notification icons  
- Stories section with user stories previews  
- Post creation section for sharing updates  
- Sidebar for events and shortcuts  

## ✨ Features  
- Clean and structured HTML markup  
- Modern and visually appealing CSS styling  
- No external libraries or frameworks—pure HTML and CSS!  

## 🎯 Goals  
- Practice and enhance HTML & CSS skills.  
- Experiment with layout techniques such as Flexbox and Grid.  
- Understand and replicate UI/UX patterns from modern websites.  

## 🌟 Future Improvements  
- Add interactivity with JavaScript.  
- Implement responsiveness for mobile and tablet views.  
- Explore adding animations for better user experience.
